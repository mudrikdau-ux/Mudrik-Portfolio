# MUDRIK DAU — Portfolio

A premium, professional, fully-animated personal portfolio website for
**Mudrik Mohamed Othman (DAU)** — Full-Stack Developer, IT Student & Technology Enthusiast from Zanzibar, Tanzania.

Built entirely with **HTML, CSS, and vanilla JavaScript** — no frameworks, no build tools, no dependencies.

---

## 🌟 Features

- **9 fully-designed pages** (Home, About, Skills, Experience, Projects, Certificates, Services, Achievements, Contact)
- **5-language support** — English, Kiswahili, Chinese, Arabic (RTL), French
- **Dark / Light theme** with persistent preference
- **Custom animated cursor** with hover + click states
- **Particle canvas background** with interactive mouse repel
- **Floating gradient glows** with mouse parallax
- **Fullscreen hamburger menu** with staggered animations
- **Scroll reveal animations** via IntersectionObserver
- **Animated counters, skill bars, timelines**
- **Interactive project modals**
- **Fully validated contact form** (mailto fallback — no fake backend)
- **Fully responsive** — desktop, laptop, tablet, mobile
- **Accessibility** — semantic HTML, ARIA labels, keyboard nav, reduced-motion support
- **404 page** with themed styling
